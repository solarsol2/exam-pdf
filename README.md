# 패스노트 PassNote

교안(PDF·PPTX)을 첨부하면 **핵심 요약 노트**와 **객관식 4지선다 예상문제 10개**(정답·해설·출제 근거 포함)를 자동으로 만들어 주는 웹앱입니다.

👉 **사용하기: https://solarsol2.github.io/exam-pdf/**

- AI: Google Gemini API (키로 쓸 수 있는 모델을 자동 감지하고, 한도 초과 시 다른 모델로 자동 전환)
- API 키: 최초 1회 입력 → 브라우저에 저장 → 다음 방문부터 바로 사용 (상단 칩에서 변경·삭제)
- 지원 파일: PDF(스캔본 포함), PPTX · 최대 5개, 합계 100MB (큰 PDF는 자동 분할 분석)
- 난이도 선택(쉬움·보통·어려움), 풀이/채점 모드, 정답·해설 모드, 틀린 문제만 다시 풀기, 새 문제 만들기

키 발급: https://aistudio.google.com/apikey → Create API key
